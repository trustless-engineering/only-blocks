# OnlyBlocks in Java

Use JDK 17 and run `./build.sh` followed by `./run.sh`.
The JDK's HTTP server and HTTP/TLS client provide transport. Java records
describe the archive structures, and byte cursors implement the archive
codecs including Zstandard. The JSON parser retains numeric lexemes for
unsigned slots and exact IDs. Both LRU caches live in memory.
